About this project

oriz brand

An AI brand-kit generator — describe a brand in one line and get a palette, font pairing, tagline, brand voice, and a logo idea, then export the tokens. This is the project info page, not the tool itself.

Open the live app → Source on GitHub llms.txt

What it is

oriz brand turns a one-line brief into a complete visual identity — a 5-swatch palette, a heading/body font pairing, a tagline, a brand voice, and a copy-ready logo-concept prompt. Its signature move: once a kit is generated, the whole studio re-themes itself to the brand it just made, so you see the identity in place. You can then export the design tokens as CSS or JSON.

Key features

  • Brief → identity — one prompt yields a full brand kit (name, tagline, voice, palette, fonts, logo prompt).
  • Live re-theme — the generated palette is applied to the page's design tokens instantly.
  • Mock landing preview — a card adopts the brand's palette + type so you judge it in context.
  • WCAG contrast check — each swatch shows its grade on white (AAA / AA / AA Large / Fail).
  • Logo concept — optional, lazy-loaded flux image; the prompt works in any image model too.
  • Token export — one-click CSS (:root custom props) and JSON design tokens.

Tech

  • Client-only Astro (static output) with a single React island for the studio.
  • AI via @chirag127/oz-ai (g4f / gpt4free, multi-provider failover, no API key).
  • PWA-installable — add it to your home screen; the shell works offline.
  • 100% in-browser — no upload, no signup, no server. Your brief never leaves your device.

AI is the core, but it degrades gracefully: if every provider is down you get a clear error and the UI stays intact.
